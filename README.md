# 🚀 Cosmic Command Deck — React Developer Portfolio

A futuristic, cyberpunk-styled developer command deck portfolio built with React 19, TypeScript, Tailwind CSS, and Web Audio API.

## ⚡ Quick Start (2 Minutes)

1. Run `npm install`
2. Open `src/App.tsx` and update `portfolioConfig` at the top with your personal bio, links, skills, and projects.
3. Run `npm run dev` to preview locally.
4. Run `npm run build` or deploy directly to Vercel/Netlify.
